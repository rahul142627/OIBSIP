# OIBSIP — Oasis Infobyte Data Analytics Internship

This repository contains all my task submissions for the Oasis Infobyte Data Analytics internship.

## About
Each folder in this repository corresponds to one internship task, and contains the source
code (Jupyter Notebook), a README explaining the project, and relevant output screenshots.

## Tasks Completed

| Task | Folder | Description |
|------|--------|-------------|
| Task 1 (L1) | [DataAnalytics-L1-EDARetailSales](./DataAnalytics-L1-EDARetailSales) | Exploratory Data Analysis on Retail Sales Data — uncovering sales trends, customer demographics, and product performance insights |
| Task 2 (L1) | [DataAnalytics-L1-CustomerSegmentation](./DataAnalytics-L1-CustomerSegmentation) | Customer Segmentation Analysis using RFM (Recency, Frequency, Monetary) features and K-Means clustering |
| Task 3 (L1) | [DataAnalytics-L1-DataCleaning](./DataAnalytics-L1-DataCleaning) | Data cleaning and preprocessing on the Titanic dataset — missing value handling, outlier treatment, and dtype correction |
| Task 3 (L2) | [DataAnalytics-L2-FraudDetection](./DataAnalytics-L2-FraudDetection) | Fraud Detection using Machine Learning — handling class imbalance with SMOTE, comparing Logistic Regression and Random Forest |

## Tech Stack
Python, pandas, numpy, matplotlib, seaborn, scikit-learn, imbalanced-learn, Jupyter Notebook
